# nextjs-demo

A fresh Next.js 15 demo project scaffolded with the App Router, built by Muse.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the demo.

## Demo features

- **Server-rendered home page** (`app/page.tsx`)
- **Client component** counter (`app/counter.tsx`) showing hydration
- **API route** at `/api/hello` returning JSON

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm start` — serve the production build
